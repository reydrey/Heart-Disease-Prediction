# Heart-Disease-Prediction
A project comparing Single Layer, Multilayer perceptrons with Support Vector Machine models made from scratch on how well they can predict heart disease from given patient data
3 classification models were made from scratch without the use of Tensorflow or any other python libraries and then used to make predictions on medical patient data. The goal was to evaluate how well these models were able to make predictions. The main metrics used to evaluate these models were model accuracy and recall.
